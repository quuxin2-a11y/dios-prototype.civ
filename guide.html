Questions

Good to know

Is it safe to install?

Yes. It's built in the open on GitHub from public code, signed with the developer's own key, and scanned for security problems on every build. Android shows a warning for any app from outside the Play Store; that's about where it came from, not what's in it.

Why isn't it in the Play Store or App Store?

It's an independent project. Getting into the stores takes developer accounts and reviews, which are in progress. Until then, Android installs it from GitHub and iPhone uses the web version.

Why no airplanes on iPhone?

Flight tracking services allow apps to read their data but block web pages. The Android app is an app; the iPhone version is a web page for now. Everything else works on both.

Does it track me?

No. Your position is only used while a feature needs it, and stays on your phone except to look up alerts and places near you. Your contacts, saved places and settings never leave your device. There are no ads and no accounts.

Does it cost anything?

No. Everything uses free public sources. A few optional extras use free accounts of your own (keys), which you add in Settings if you want them.

Can it identify people or cars?

No, by design. It doesn't read licence plates, identify vehicles, track people, or show private individuals' names. Records show organisations only.

Is the emergency advice reliable?

It repeats official alerts word for word and ranks safe places by fixed, visible rules. It isn't a prediction and it doesn't replace emergency services. In danger, call your local emergency number first; the app shows it with a call button.

How do I get updates?

On Android, download the newest file from the same GitHub link and install it over the old one; your settings stay. The web version updates itself.

Something isn't working

Open ⚙ Settings → Testing → System check. It shows which sources are answering and lets you share a report. A source that doesn't answer is usually busy; try again in a few minutes.
